## 既知の制約

- 入力内容と生成結果はブラウザのメモリ内だけで扱い、再読み込みまたはタブを閉じると失われる。
- Clipboard APIが使えない、または権限がない環境では、プレビューから手動でコピーする必要がある。
- 生成内容は固定テンプレートと利用者の編集内容に基づくため、既存リポジトリの構成やコマンドは自動解析しない。
- キーボードのみでの主要フローは、実機環境でのTab順・Enter操作・必須エラー時のフォーカスを確認するまで公開判定の保留条件とする。

## 公開判定

キーボードのみの主要フローを実機環境で確認するまで、公開判定を保留する。その他の主要フロー、自動検証、公開環境のHTTPS・静的ファイル・404は確認済みであり、P0不具合は検出されなかった。
